# Тренинг навыков DBT — приложение

Это PWA по [техническому заданию](ТЗ-Тренинг-навыков-DBT.md), шаг 2: первая версия без сервера. Образец внешнего вида — [прототип](dbt-group.html).

## Что готово

- **Сегодня:** шапка сессии, вопрос недели с ответом, задание недели, отметки недели.
- **Практика недели:** форма из 7 пунктов и история практик за неделю.
- **План:** 24 сессии с датами. Прошедшие отмечены, текущая выделена, по нажатию сессия раскрывается.
- **Дневник:** запись за сегодня или вчера (одна на день, её можно поправить): эмоции, сила, навыки, заметка. Навыки сами попадают в таблицу навыков на неделю этой записи. Галочка «дневник» ставится сама, когда за неделю набралось 4 дня (число задано в `app.js`, `DIARY_DAYS_FOR_MARK`).
- Записи хранятся только на телефоне, в IndexedDB. Приложение просит у браузера постоянное хранение.
- Черновики ответа и практики сохраняются сами, пока человек печатает.
- Если хранилище недоступно, приложение предупреждает и не теряет набранный текст.
- Офлайн-режим и установка на главный экран: service worker, манифест, иконки.

Пока это заглушки: Навыки, Группа, Анализ цепочки, «Сохранить копию» и «Загрузить копию».

## Файлы

| Файл | Что в нём |
| --- | --- |
| `app/data.js` | **Всё содержание:** расписание, переносы, сессии, вопросы, задания, навыки. Правится без программиста |
| `app/app.js` | Экраны и логика |
| `app/db.js` | Хранилище на телефоне (IndexedDB) |
| `app/sw.js` | Работа без интернета |
| `app/styles.css` | Внешний вид, светлая и тёмная тема |
| `app/fonts/`, `app/icons/` | Шрифты Onest и Unbounded (лицензия OFL) и иконки приложения |

## Как поменять расписание или тексты

1. Откройте `app/data.js`.
2. Чтобы перенести встречу, впишите её в блок `moves`, например `5: "2026-11-05T19:00",`. Все следующие встречи пойдут раз в неделю от новой даты.
3. Когда ведущий объяснит анализ цепочки, поставьте `chainEnabled: true`.
4. Выложите обновлённый файл. Участники получат изменения, когда в следующий раз откроют приложение с интернетом.

Если менялись другие файлы (не `data.js`), поднимите `VERSION` в `app/sw.js`. Тогда участникам покажется кнопка «Обновить».

## Запуск на компьютере

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory app
```

Затем откройте http://127.0.0.1:8765.

Чтобы проверить другую неделю, добавьте к адресу дату: `http://127.0.0.1:8765/?date=2026-12-20`. Приложение будет считать, что сегодня 20 декабря.

## Проверка на телефоне

Офлайн-режим и установка на телефон работают только по HTTPS. Поэтому для проверки папку `app` нужно выложить на хостинг, например на GitHub Pages.

- **iPhone:** откройте адрес в Safari, затем «Поделиться» → «На экран Домой».
- **Android:** откройте адрес в Chrome, затем меню → «Установить приложение».

Что проверить: приложение открывается в режиме самолёта, ответ и практика сохраняются после закрытия приложения.
